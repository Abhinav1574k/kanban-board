# Kanban Board with Backend Persistence

A full-stack Kanban board application built as part of the Veda Technology Web Development Internship.

The application allows users to create boards, manage columns and cards, move cards between columns, and persist board data using a backend database.

## 🚀 Features

- Create and manage Kanban boards
- Create columns for different workflow stages
- Add, edit and delete cards
- Move cards between columns
- Drag-and-drop card reordering
- Persist card positions in the backend
- REST API for CRUD operations
- Multiple boards support
- Responsive and user-friendly interface
- SQLite database persistence
- CORS-enabled Express backend

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- CORS

### Database
- SQLite
